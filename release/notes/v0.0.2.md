# v0.0.2 — Initial Developer Preview

ActQL's initial developer preview provides a TypeScript/Node library and a
Native CLI. It is intended for developers trying the local engine, mock
workflows and explicitly configured Remote Hosts.

## Install

```sh
npm install @actql/node
npm install -g actql
```

The selected npm channel is `latest`. To keep this preview version fixed, use
`@actql/node@0.0.2` and `actql@0.0.2` and retain your package lockfile.

- **TypeScript/Node:** `@actql/node` provides the Local implementation and the
  public Client entry on macOS arm64 and Linux x64/glibc. `@actql/sdk` is the
  separate Remote Client.
- **CLI:** the same `0.0.2` release targets macOS arm64 and Linux x64/glibc.
  The npm launcher needs Node 22.22.0 or newer; the Native executable runs without Node. Keep npm
  optional dependencies enabled to install the matching binary package.
- **Python:** distribution is deferred and is not an initial installation path.

The current macOS qualification environment is 26. An earlier minimum is not
declared until the final binary ABI and actual installed acceptance establish it.

The CLI supports Local projects, quick queries and saved Run/Result access,
as well as explicit Remote HTTPS/mTLS connections. `actql init` can create a
mock deal-review project without live provider credentials. Project Store
adoption, Checkpoint decisions and Remote authentication remain explicit;
installing a package does not grant access to external systems.

## Preview stability and scope

Public APIs, command and query syntax, and storage formats may change
incompatibly in later previews. Do not assume that a future package can open
all state written by this version; preserve project state and the version used
to create it before upgrading.

This release does not include Intel Macs, Windows, musl, managed ActQL Cloud,
browser execution, every live provider integration, or a
complete Debug/fault matrix. Mock-provider and fixture acceptance do not imply
live-service support. Check each Connector's documented capabilities and setup.

Start with the [README examples](../../README.md#2-get-started), the
