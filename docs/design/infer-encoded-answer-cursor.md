# Encoded structured-answer admission

An installed physical codec may return the selected structured-answer JSON
text instead of constructing a runtime value. This text is distinct from the
original HTTP response Artifact. It cannot mint completion, send authority,
an Artifact identity, a saved-response ACK or a public provider capability.
The existing installed profile and original Model Entry remain prerequisites.

The original Model execution retains the physical terminal observation and
advances the existing Source JSON parser, Decode admission and typed Value
admission as child cursors. Each advance performs one child transition and
charges one original logical work unit, independent of quantum. The profile's
finite parse-work allowance covers these three stages cumulatively. Response
UTF-8 bytes, parse nodes/depth and the original typed-value limits remain
independent limits; exhaustion does not increase any reservation.

Data-key parsing preserves original Unicode and newline values. Malformed
JSON, duplicate fields and output-contract violations fail before capture or
public output. Unknown quantities remain absent, while actual observed usage
is retained even when answer admission fails.

Only a value completed by these child cursors can be retained as the original
call's decoded response. Existing nullable observation validation, evidence
issuance, bounded response/output hashing and settlement then operate on that
same response. Successful decoding is not durable persistence. Settlement ACK
does not invoke a user callback; original physical cleanup runs separately and
may retain its retry handle. Cancellation fences new calls while a previously
obtained response is settled without publishing a partial result.

Encoded text, Source/decode trees, cursor records, typed output, metadata,
response/output writers, pending evidence and adapter backing can overlap.
These references remain part of the existing original Run/Ledger cumulative
funding obligation, through ACK and any failed cleanup. Cursor cancellation
clears its owned parser/admission frames; successful physical cleanup clears
the original decoded-response reference. Neither operation proves external
copies or remote execution were reclaimed. No new Store, Scheduler or Ledger
is introduced, and these APIs alone do not establish funded public async use.
