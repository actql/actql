# Prepared publication Environment in Run Host

The Run Host facade exposes the existing publication owner's prepared Environment
through a nominal handle. It retains the exact admitted Environment and complete
publication wire. Reuse checks those originals before forwarding the prepared
catalog and Effect target parts to the existing preparation owners.

Each Program and its Parameter values still receive their own preparation. An
omitted prepared handle follows the existing admission path. Saved Source
originals retain their original primary recipe during restoration.

These handles contain immutable installation metadata. Current authorization,
acquisition, Preview approval, durable claims and Run outcomes stay with their
existing operation owners.
