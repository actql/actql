# Original Effect publication evidence

## Complete immutable admission

The existing publication owner admits the complete computation/captured chain,
Result dependency inventory and Set/member/final receipts. Its retained
`EffectfulFinalRunEvidence` contains the original final Receipt, admitted Set
outcomes and the immutable contracts needed by later publication checks. It
does not grant an Effect operation, current Account permission, a Store commit
or physical cleanup. The existing raw admission/issuance profiles remain
available for their distinct callers.

The public facade returns the existing nominal PublicationContract for this
original final Receipt. Its existing private publication-original association
retains the checked Core value and its exact input association. Copied surfaces,
another facade namespace or changed constituent vectors cannot substitute that
association. This adds no global permission registry or public Completion owner.

## Retained outcome and reconciliation

Outcome and all-unattempted observations read the original admitted Set facts.
They neither parse raw member wires again nor inspect current authority. The
existing reconciliation writer can consume this same admitted partition and
the original manifest's declared Result names. Only an actual Unknown partition
produces reconciliation state; failed and unattempted rows do not become Unknown
or success. The raw reconciliation entry still performs its complete receipt
admission and uses the same writer and refusal order.

The same retained final chain can project a known-failed Run through the
existing unpublished failure writer. Only the complete admitted partition can
select this path; successful and Unknown partitions refuse it. The original Run
identity and manifest supply the Result inventory, all unavailable because no
publication occurred. This historical state does not confirm physical stop,
release resources, grant current authority or permit another dispatch. The caller
still observes the original durable revision, current authorization and CAS; an
uncertain state write remains Unknown until its original commit is observed.

## Original Result occurrences

Restored Results pass their actual Definition, Artifact, derivation, ordering and
retention contracts to the existing occurrence/artifact validators. Independently
observed logical value, schema and effective policy identities must match. This
does not issue a replacement derivation, scope, issuer, ordering or witness, and
does not supply Result-read authority. The existing operation's original/fact
association determines when a new observation needs validation.

## New publication facts

The retained complete chain and Result inventory are not admitted again for each
helper. Publication still checks new durable bindings, Request, Attempt and
PublicIndexEntry against the same originals. The private facade records only the
original validated index DATA. A changed input or failed publication validation
clears that association before any fallible work; an older successful check
cannot make the later failure publishable.

An Effect succeeded-state projection requires its original prepared/compilation/
allowed/Definition tuple, the actual admitted successful outcome and checked
publication facts. Declared Result inventory comes from the retained original
Effect compilation. Current per-Result availability, durable CAS/commit
observation, Run revision and physical acknowledgement remain with the Host.
Validation or a projected wire alone establishes none of those observations.

## Representation and lifetime

A complete managed representation copy preserves the original completion
occurrence through the existing builder, receipt and publication bridge. The
existing copy loop must commit every row, in order, from the same original
owner and target. Partial, reordered, mixed-original or manually admitted rows
cannot seal that association; equal row values or CIDs are insufficient. An
empty original can transfer its occurrence without inventing row work. Failure
or cancellation cannot issue a successful receipt.

Only bounded identity, target and copy-progress metadata are retained, not the
old row buffers or an additional output use. The common construction quote
backs its 320 logical bytes using the existing representation tariffs and Task
Ledger. The original and converted output still have their independent current,
managed-generation, publication and cleanup fences. Sharing an occurrence does
not grant execution, Model ownership or export authority.

For a computed Effect suffix, the original captured task owner seals bounded
completion DATA only after the actual output and its exact admitted inputs pass
completion validation and resource settlement. It retains the consumed unary
producer coordinate and the original completion occurrence, without rows,
execution callbacks, input bindings or physical holdings. Each suffix edge must
match that successful completion in the same checked Run and Unit; static graph
reachability, a done flag alone, equal values or equal CIDs do not supply it.
The original Model and final Result still require their complete current,
availability, receipt and export lifetime fences. Historical correspondence is
neither currentness nor permission and cannot reopen a retired Result.

Only Effect DAGs allocate these completion records. The existing original
Effect control reservation funds their bounded per-task representation beyond
individual body/output retirement. The static Plan and actual-row control paths
compose that cost once each as exclusive alternatives, not as per-task provider
workspace. Stopping the Run revokes new artifact issuance and drops this DATA
before the original control token retires; pending physical cleanup retains its
existing owner and is not inferred from the DATA. Pure task construction, the
320-byte representation-copy quote, global tariffs and policy ceilings remain
unchanged.

The Core record retains twelve fields and six bounded vectors: five snapshots
of actual Result contract references, plus declared Result names from the
admitted manifest. Existing decoded contracts and admitted Set facts are retained
by reference; raw member receipt bodies are not reissued as another contract.
The public facade's original snapshot retains its fourteen constituent fields
and six bounded vectors on the same final Receipt association. Own DATA and existing Core Int length checks precede the snapshots. Per-wire
node limits are not repurposed as a Result/member-count ceiling. These are actual proportional holdings,
distinct from parser/writer workspace, not additional user capacity knobs.

The consuming parent must back these selected inventories and their temporary
overlap before admission. The getters supply no backing, and releasing immutable
evidence references is not physical retirement. Resource children, pending
callbacks, actual Store outputs and failed cleanup keep their existing owners
and duties; consumed work, Unknown and no-resend history are not refunded.
