# Native command finite storage quote

The compiled Native command installer selects finite Read and SQLite facilities
and the original OS platform facility. It does not issue a complete-demand
estimate. The former demand-only selector alternatives had no production
constructor and are not supported installer modes.

`local_command_native_storage_quote.mbt` retains the actual finite path:

- The WAL region calculation, MEMSYS5 blocks, simultaneous Journal result copies,
  two overlapping pointer arrays, and recovery buffer establish necessary
  payload coexistence. They do not establish a complete SQLite heap demand.
- The finite Read check includes one aligned crypto extent, the physical
  inspection layout, and the independent bootstrap/workspace/Read reservations.
- Consumer, Read domain, SQLite domain, SQLite total, and shared control ceilings
  must each cover their original selected quantities.
- Numerical platform or external SQLite substitutions, including zero, remain
  invalid. An absent heap/control selection is not replaced by a default.
- `command_domain_necessary_bytes` must still return the actual selected physical
  provider's layout. No test or unselected binary supplies a synthetic minimum.
- The same platform-original admission remains mandatory before acquisition.
  A successful arithmetic check issues no Host, Read, capacity, or permission.

The private necessary-payload, Read-subset, final-ceiling, and Journal-subset
functions are used by the production finite quote. Tests exercise these same
functions, not a copied demand implementation. Actual finite-provider refusal
is tested separately from positive arithmetic facts. Assertions that depended
only on an uninstalled complete-demand selector were retired with that mode;
those assertions are not relabeled as successful physical Owner coverage.

Supported-platform physical Owner tests and their original capacity guards
remain authoritative for acquisition and cleanup. A passing numeric or static
check does not establish that an unsupported platform can execute those paths.
