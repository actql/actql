# Graph path default: fixed-source acceptance

## Selected rule and implementation boundary

The pinned GoogleSQL reference `d82db99a923a46571f543a13899dc791a7b6f743`
[Path mode](https://github.com/google/googlesql/blob/d82db99a923a46571f543a13899dc791a7b6f743/docs/graph-patterns.md#path_mode)
selects WALK when no path mode is authored. The previous Frontend required an
explicit mode even for supported fixed directed patterns. Omitted modes now
select the existing Walk AST value, using the same ordinary Program lowering
and common Graph/traversal owners. Explicit TRAIL and ACYCLIC are unchanged.

Verified implementation and clean packed source:
`fb64a7087839c9118d6310017f3f76f76557bc24`.
The branch starts from `af1687a202455a9bcc85113550cd7dbd63dd1627` (#237),
and its common Graph dependency remains C
`51376bca11d57b775aa22d42453176f8ad1f681b` (#164). No later C revision,
legacy Graph conversion, alternate checker or frontend execution owner is used.

The default does not expand unsupported quantifiers, nested/optional patterns,
search prefixes or PATH/PATHS sugar. It also does not bypass traversal ceilings.
Those remain separate coverage obligations.
