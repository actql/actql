`actql-model-response-profile/0.1` support body. Its self identity excludes only
root `self_cid`. The referenced profile, self identity and recomputed canonical
body agree. It does not replace ModelTask/evidence/capture versions, private
`model-physical-port/1`, SDK interface v4 or package release versions.

The Common MoonBit reader performs bounded canonical admission and semantic
cross-checks. `check_model_response_profile_binding` matches an already checked

That plain record is deliberately not an installation or permission token.
The existing Publication artifact Owner seals/adopts the closed body; new
profile admission refuses noncanonical encodings without changing old readers.
No Model execution, async installation, capture-success issuer or public
capability is enabled by this registration.

The body binds one exact Task and input/output schema pair, avoiding a new
schema-subset language. Builder/codec/validator identifiers, revisions and
Artifact CIDs bind their actual implementations. SDK package/version/interface
and an original transitive-lock Artifact are explicit, or the whole SDK member
is NULL for independent HTTP. A configuration referencing this profile does
not occur in these referenced originals; the identity graph remains acyclic.

`completion.basis` chooses generation endpoint finish or native Decision
envelope validation. Transport EOF, the actual endpoint envelope and checked
output are all required. Their true constants are requirements, not evidence
that a response fulfilled them. Only the registered codec's actual result can
participate in successful adoption. SDK defaults and opaque metadata never

## Resource and observation boundaries

All physical quantities are positive finite signed-Int-compatible integers;
active/unsettled slots are each at most four. The profile declares one request
and disables retry, fallback, hedging, tools, repair, cache, media fetch,
workflow restoration, SDK telemetry and redirect. These declarations need
actual verified enforcement before public installation.

The reader checks only the necessary backing-plus-one-chunk-plus-header minimum
using wide checked-domain arithmetic. It does not adopt a new total formula or
modify the existing `81920` ceiling. C retains the simultaneous sum of all
prepared input/key masks, raw response backing, SDK copies/parse objects,
Promised/reader/record holdings, original Entry/ACK, unknown/capture inventory,
workspace and cleanup-pending custody. A short view does not retire its backing,
and post-read checking does not bound upstream chunk allocation. Parser
operational/isolation bounds also need verification; bytes alone do not prove
CPU bounds. No unfunded new public buffers are installed here.

Supported observations are a duplicate-free subset in a fixed normative order.
Support is separate from actual observed presence. Actual usage/provider fields
and metadata remain independently nullable; unknown, zero, empty object and
nonempty original Unicode/newline-bearing metadata retain distinct meanings.
The initial native Decision law references the existing precision profile;
this does not restrict the generic answer shape to two decimal places.
