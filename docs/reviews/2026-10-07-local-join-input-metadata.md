The selected bounded Join used whole-string equality and UTF-8 name scans in

source-key regression failed before the production change: a quantum-one resume
charged more than four logical units in one metadata step (`run-vETDbJ`). This
is a kernel-boundary counterexample, not a measured public cancellation delay.

`bounded_join.mbt` now borrows checked input and output schema names. It uses the
existing `ChargedRowMetadataLookup` for keys and projected sources, and
`RowNameCharge` for output names. Lowering already constructs projection entries
in exact output-schema order, so qualified output spelling is borrowed rather
than rebuilt. No new evaluator, scheduler, identity, wire format or API is added.

Each active continuation reserves one workspace slot. Lookup and name charging
do not overlap. Terminal lookup releases its slot before committing column
metadata. Cancellation keeps inputs and pending cursors until physical stop and
cleanup; the same owner closes each cursor once. Accepted output custody remains
separate from the execution state's cleared metadata arrays.
