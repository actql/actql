# Graph argument CHECK acceptance registration

The normal clean installed public-query CHECK path now registers the authored
Graph argument diagnostic matrix on Embedded Local and trusted HTTPS. The
existing `--graph-diagnostics-only` selection and default full corpus both run
it. Other narrow query selections retain their original scope. The ordinary
package producer, manifest/digest checks, private installation, transport owners,
query execution inventory, output allowance and deadlines are unchanged.

The shared assertions consume the existing fourteen literal vectors unchanged.
They retain the current WITH/GRAPH grammar, independently authored UTF-8 ranges,
emoji/CRLF and decomposed Unicode prefixes, decoy comments and repeated operation
occurrences. Each invalid outcome must retain the exact typed operation/issue,
owned original source revision and range. SDK resolution must recover the exact
token and reject stale text, an altered revision, a different source outcome's
location and a serialized outcome. These SDK custody controls do not construct
or claim coverage of a foreign parser cursor.

The remaining fourteen controls preserve source-free weak/strong components,
private-kind redaction, zero/fractional output-count errors, invalid Subgraph
selectors, and the existing Subgraph `where` implementation limit. Separate
absent and denied Source publications must suppress dependent Graph reasons and
locations, while an independent supplied-value error remains visible. They use
the same real installed DuckDB source profile with immutable Host installations.
No new language rule or checker is introduced.

Each transport writes its exact expected/completed 28-case inventory, per-case
observations and terminal receipt. The coordinator requires all 56 completions;
it rejects missing, reordered, duplicate, unfinished or nonzero-execution
receipts separately from the unchanged query execution inventory. Observations
cover Source database opens, native I/O/read sessions, accepted Runs and durable
dispatch/physical-start reservations. HTTPS additionally observes its supported
`beforeDispatch` hook; the Local receipt explicitly has no such hook. Receipts
are retained by the ordinary evidence collector, including partial failures.

## Verification boundaries

The exported parser and checker origin boundaries remain those adopted by
#1805 and #1846. Physical foreign equal-text snapshots/Programs and Generated
origins remain the existing owner probes in
`src/graph_argument_origin_probe/public_origin_test.mbt`; the public SDK cannot
supply such trusted cursors. Those probes remain a separate acceptance
obligation, not a property proved by installed text CHECK alone.

Focused source/receipt checks:

```sh
node scripts/local-checks.mjs test node --timeout-seconds 60 --kill-grace-seconds 5 -- scripts/graph-argument-origin-literals.test.mjs scripts/graph-argument-check.test.mjs
node scripts/local-checks.mjs test moon --timeout-seconds 60 --kill-grace-seconds 5 -- --target js src/graph_argument_origin_probe
node scripts/local-checks.mjs test node --timeout-seconds 60 --kill-grace-seconds 5 -- --test-name-pattern 'Graph argument CHECK acceptance matrix' adapters/host-node/client-check.test.mjs
```

The normal packed consumer remains:

```sh
ACTQL_PACKED_CLIENT_PACKAGES="$PACK" node scripts/test-packed-public-query.mjs --graph-diagnostics-only --keep-artifacts
```

Use the existing guarded clean-source producer/consumer recipe, unchanged
package pins and compiled runtime identity. Registration and receipt validation
are not runtime acceptance. This change does not itself establish executed
owner probes, Local/HTTPS acceptance, main adoption or completion of #424.

The shared packed preflight also carries the same three fixed-count corrections
as #2158: 4181 total, 2616 successes and 1512 refusals (53 execution failures
unchanged). #1808 added four general-ARRAY positives and removed one obsolete
refusal; the current inventory pin already records those changes. Only the
stale assertions are corrected, identically in both PRs. The independent
inventory JSON, exact enumerator and digest comparison are unchanged.
