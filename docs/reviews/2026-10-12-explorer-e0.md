## Local ownership and Gateway seam

`@actql/node.connect` selects the installed `@actql/local-node` provider only
for explicitly embedded Local. An explicit endpoint uses the existing connected
Host. Each embedded Client owns a private lease on the compatible installed
Host; final close uses its existing shutdown/cleanup protocol. Close does not
cancel a Run, delete retained Results or reopen a failed cleanup. Explorer must
not open a second Host against an already owned Store.

The Local Gateway can accept an existing SDK Client lease or explicitly create
one through `@actql/node`; it may not assemble Owners or borrow Native/Resident
authority. Attach is read-only original-Run admission, not a submit. Browser
scope epochs discard replies; they are not Host authorization or durable fences.
Every request still uses current Host authorization.

Hono/Node Gateway and built SPA remain to implement. Required launch/security
acceptance is exact `127.0.0.1` bind, Host/Origin validation, bounded paths/bodies,
short-lived one-use bootstrap, protected session/CSRF, built-assets-only serving,
and no browser credentials/Provider URLs. Tab closure must not mutate a Run.

## Finite initial E1 code and acceptance limits

`packages/explorer-ui/read-model` is shared presentation/data-source preparation:
original logical ports, both roles of a shared Join input, unresolved Stage
locators, immutable models, finite refusal, public Plan/attach/inspect/Result
description calls and delayed-scope result/error discard. Its semantic fixtures
are independently authored; they are not compiler/public Host acceptance.

Changed component cases correspond to M05/M06, I01/I03, A02/O07/B04, B01 and
capability-unavailable H01. Static calls create no submissions; existing Run
calls have no wait/cancel/resume/reconcile; Result metadata creates no payload
attempt/grant/open. These are call-routing component facts until an actual
public Host and distributed package confirm R01/R02 and related disclosure.

Outstanding E1: React/Flow/accessibility, Hono Gateway/launcher security, current
scope/authority binding, terminal pending polling, explicit payload/receipt reads,
Cloud existing-route embedding after appropriate cohort adoption, actual build,
external package/assets/peer closure and selected real public read acceptance.
E2–E4 and the existing Native Local/Debug CLI goals are retained. No Hosted CI,
Heavy producer, Provider operation, package publication or deployment is added.
