# Original Resident Review upload

A retained original Review may exist without a live physical Review factory.
The genuine consumer context can now join its original journal report to the
confirmed Store continuation and upload that projection through the existing
report-ACK and HTTP Owners. It does not prepare another Preview or access a
Provider.

The live Review and original-context entry points share one private transport
implementation. Only their nominal Owners supply original bytes. The shared
path preserves the 65,536-byte projection limit, exact report/journal comparison,
typed durable ACK admission, and current disclosure/custody checks before ACK,
after ACK, and after artifact save. An already accepted original report is not
sent again. A 204 confirms artifact transport only; it does not authorize an
Effect, settle an unknown write or release resources.

The existing physical fixture adds the original-context path after live Review
publication: denied authority and foreign Store authority refuse before upload;
revocation after ACK refuses upload; revocation after remote save retains the
original responsibility; explicit retry sends the identical original projection.
Its independent peer requires exactly two report requests and five identical
artifact uploads, including the existing live retries. Provider observation and
Store reservation counts must not increase.

These new physical assertions are compile-only until the existing Native
verification window is assigned. The existing portable original-continuation
codec tests are separate executed evidence. No production evidence-read
permission is enabled; the trusted current Host policy connection remains
required. This unit does not restore the physical Review/row/Ledger handle or
complete public approval, Effect execution, Named Result or release.
