# Native original Effect producer capture

## Connection

`ResidentEffectProducerExecuted.prepare_dependency_capture()` joins the original
completed Source Runtime and journal to the existing checked acquired-Unit pins,
Result exporter, semantic Artifact issuer and producer binding token. The finite
one-Source/two-task boundary requires the complete single producer Result and
derives its name from the checked occurrence. Callers cannot replace its name,
observation interval, invocation, Run lifetime or original authority.

Retention is a trusted publication policy input, not Effect approval. The
acquired evidence, relation/schema bodies, original Observation Set and Run
Invocation accompany the actual Artifact for the separately admitted receiver
capture. The existing receiver admission still validates its actual Transfer,
checked consumer edge, current authorization and live input borrow.

## Ownership and failures

`ResidentEffectDependencyPins` wraps the existing acquired-Unit borrow set and
export workspace. It does not own or close the producer Runtime, Source,
Transfer, receiver holding or Named Result. Preparation and streaming identity
passes share an explicit finite step budget and never reacquire Source data.

Every failure after borrowing closes the export and returns the same borrows.
If that return is unconfirmed, the failure retains the same pending handle.
Close is idempotent only after the existing borrow Owner confirms its return.
Closing these pins cannot establish physical cleanup or a released task.

The actual Native holder/Transfer fixture calls the production adapter. It
checks original saved times/evidence, bounded export interruption, independent
receiver admission, reentrant sender-borrow return, independent Result rows and
schema, and unchanged underlying Source/consumer reservations. Its physical
producer/receiver cleanup remains separate.
