## Repair and scope

The shared projection parser accepts the same explicit name with or without AS.
It preserves quoted names and does not consume unquoted reserved GoogleSQL
keywords as optional aliases. The complete reserved list was compared against
the pinned lexical reference. This affects SQL/Pipe SELECT, EXTEND, AGGREGATE
and existing selected analytic projections. It adds no AST interface or
lowerer/evaluator special case. Name resolution, sibling visibility, demand,
column order and types retain their existing common contracts.

Unsupported clauses remain syntax rather than accidentally becoming output
names. Anonymous computed/function outputs remain a separate coverage gap;
aggregate and analytic outputs still require a name. No new public Result
name is invented.
