# Original installed CheckEnvironment construction

- Responsibility: The existing Common wire reader and checker configuration
  constructor own these quantities. The installed Host separates their two
  synchronous calls so its original SourceInitialization material can reserve
  each constructor before it runs. These APIs do not create another preparation
  controller, Resource, Catalog interpreter or execution authority. The legacy
  complete admission entry continues through the same two reader helpers.
- Inputs and outputs: The already-funded immutable JavaScript document supplies
  exact same-input byte, node, container, field, key, member and manifest counts.
  Quotation performs scalar arithmetic and shared constructor expansion, not
  parsing, normalization, hashing or semantic checking. The wire quote returns
  the existing opaque ExecutionCapacity representation. The wire constructor
  returns its genuine WireEnvironment; the second quote and constructor receive
  that exact original. The private installed second call supports an empty
  ModelTask section and the same seven explicit profile flags. Populated models
  require their separate constructor owner and are not silently treated as empty.
- Identity: Quoted geometry is DATA and cannot authenticate an environment or
  replace its input. Wire admission still checks canonical bytes, evidence CID,
  member identities, ordering, duplicate snapshots and connector manifest
  references. The second constructor borrows the admitted wire itself, not a CID
  lookup or equal-shaped replacement. Compatibility numeric-profile selection
  remains before wire admission and rejects an unknown profile exactly as before.
- Ownership: The JavaScript input String remains at its existing owner. Wire
  admission owns decoded Source text and spans, the immutable decoder index,
  member Cursor/Entry/CID records and section arrays. Empty ModelTasks owns its
  original entries and selector containers; CheckEnvironment owns its profile
  records and copied request-policy array while borrowing that wire and ModelTask
  owner. The full and RelA bridges have one source and one Common capacity tariff;
  the generated RelA mirror is not a second semantic or resource issuer.
- Synchronization: Fund parsing and freezing the JavaScript original before its
  census. Convert and reserve the complete native wire quote on the same existing
  SourceMaterial before clientProgramReadCheckEnvironmentWire. Retain its actual
  return before selecting that quote's retained part. Quote and reserve the
  empty ModelTask/checker wrapper separately, then construct from that original
  wire once. Every independently admitted composition input retains its own
  constructor debt; repeated consumers borrow the retained exact result rather
  than encoding, parsing, hashing or checking the same wire again.
- Failure: Invalid scalar domains return no quote. Native reader limits stay
  65536 bytes, 4096 nodes, depth 64 and 256 members. ModelTask limits also remain
  unchanged in the compatibility helper. A failed read or constructor cannot
  select the successful retained quantity. The installed empty-model quote and
  constructor both refuse a nonempty ModelTask section; the legacy complete
  entry retains its existing populated-model behavior. No missing quantity is
  interpreted as zero or as permission to retry a constructor unfunded.
- Cancellation: These synchronous quantity functions acknowledge no physical
  cleanup, stop or release. The original SourceInitialization material owns
  currentness, reentry refusal, outstanding I/O, failure debt and retirement.
  A retained-only projection is numerical DATA and is usable only after the
  original caller observes successful return and retains all returned owners.
- Resources: The wire recipe composes the existing literal JSON construction
  family with the actual largest decoded key's NFC/LF workspace and the summed
  keys' normalized-output bound. This preserves normalized parser failure paths
  without treating a large DATA value as one enormous identifier. Strict UTF8
  decode/encode storage, decoder index/key/ancestry controls, envelope/member
  collections, snapshot uniqueness, connector-manifest validation, canonical
  writer/hash and raw SHA finalization remain distinct constructor families.
  Success retains index growth conservatively, Source spans/text and original
  member/section owners. Synchronous parser, normalization, hash and discarded
  manifest scratch is excluded only from the successful retained projection.
  The zero-task quote still counts its actual empty Array/Map, limits, budget,
  typed outcomes and checker/profile/request-policy wrappers. Conversion uses
  execution_relation.preparation_representation_cost and execution_capacity;
  no new byte factor, configured-limit proxy or backend-memory claim is added.
- Extension: Catalog admission, PreparedSourceCatalog provenance, publication
  context/alias/target construction and populated ModelTask schema/generation/
  data-handling construction are outside this inventory. Reusing a Catalog for
  publication requires that exact CheckEnvironment owner and original admission
  bounds, including contents depth; observed usage cannot prove a tighter depth
  bound or authorize rereading. New reader allocations, output owners, flags or
  constructor lifetimes require corresponding quantity review. Mirror changes
  go through checkRelaClientBridges in scripts/client-bridge-mirrors.mjs.
- Verification: wire_admission_construction_wbtest.mbt covers retained versus
  peak quantities, actual largest-key normalization versus large value text,
  inconsistent geometry and the zero-task quote's refusal of a genuine nonempty
  wire. Installed-funded-environment component tests cover the real bridge
  sequence and retained-original reuse with explicit diagnostic Resource ports.
  Source sidecars establish only exact source/interface correspondence. Neither
  those checks nor this inventory establish complete Catalog/publication funding,
  physical backing, normal-package artifacts, merge or release acceptance.
