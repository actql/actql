# Original parent read transport

The existing installed Host selects a transferred parent domain and prepares
its original physical read context. Its private selected-profile caller may
then request one `InstalledArenaOriginalRead`. Five Int64 fields declare the
bootstrap, workspace and read envelope within the existing allowance; neither
the C shim nor Python grants resources or supplies missing ordinary funding.

Code roots use the regular C emission of source `eb1650c70a6af3490f1e0026312a5485f9037cb2`,
5876434 bytes, SHA256 `fe55b57746c9add0b57b3ccc0c9786539d922e86fd33f40f59f608a8df2dcb19`.
It shows borrowed Host/domain/carrier inputs and owned immutable replies and
getter references. The shim uses those opaque tags and typed callbacks only.
It does not inspect generated fields, issue a Ledger, register another provider
or directly release physical backing.

All output slots are persistent and empty before calls. Original Host, domain
and optional read carrier are captured separately before the reply is dropped.
Every drop compares all original references. Confirmed Close/Ok or no-carrier
Prepare refusal is required before data references are cleared and decref'd.
Native imported Unknown has a distinct issue family (9), retaining the same
original responsibility instead of becoming a known refusal or another attempt.

`_OriginalParentReadCustody` registers in the original Python domain after its
existing process/thread/reentry entry succeeds, before FFI can publish custody.
Known entry refusal changes no registration or busy ownership. Response loss,
malformed identity/opcode and lost slot-clear acknowledgements stay Unknown and
cannot resend prepare, leave or close. Known leave/cleanup refusal permits an
explicit retry of the same Owner; it never re-enters or reconstructs a context.

The consumer brackets the whole managed input/result/failure lifetime. It must
drop its scoped Runtime and asset aliases before the outer installer asks the
same carrier for final retirement. Python scope flags remember only confirmed
entry/leave, and cannot acknowledge last-alias retirement or Run completion.
Parent domain cleanup remains blocked until original read data-drop ACK.
The one-attempt registration tombstone is removed only at parent retirement.

The selected producer includes the new shim and forces the actual prototype
header into its generated C compilation. The matching diagnostic retains one
original provider/TLS. It is not a new numerical profile, Wasmtime/worker build,
wheel cohort, public Client execution or original Run recovery acceptance.
