# Non-test installed arena anchor

This private Source unit prepares a non-generic `InstalledArenaHost` entry for
the selected Native control component. The Host itself is the original anchor
passed to the existing generic NativeHostBootstrap; no BootstrapTestOriginal,
dummy Source or copied MoonBit ABI layout is used by the implementation.

`prepare_installed_arena_host` is a trusted installed physical supplier intent.
Its metadata is neither an authenticated installation nor a capacity grant.
`acquire` must obtain actual original arena backing through the existing
reserve-before-acquire Owner path, store its same partial carrier before claim,
and retain the primary issue on failure. A copied reference shares acquisition
state. Preparing another metadata record cannot consume a foreign allocation.
The normal Python factory still rejects missing complete installed funding.

Allocations, borrowers and delegations contain only their original existing
tokens plus the same Host. Accounting and byte-domain refusals remain in the
Resource/NativeBootstrap Owners. Closing can return the original physical reader
and retry the same cleanup, but cannot reopen or reset failed acquisition.
Host/supplier/backing references break only after the full original close ACK.
No new lifetime queue, ledger, Run controller or durable-recovery claim exists.

The added `NativeHostBootstrap.require_current` projects only original mutable
arena availability after claim. It is not Run, VM, publisher or worker permission.
Unrelated loader/VM/Python domains remain unknown; numeric profile adoption,
ordinary SDK entry, runtime/wheel and product E2E remain incomplete.

The five Native cases passed at exact Source
`67573de5536cda80a86578bc8815f6d78c0994eb`, run-L9cTwr, with the pinned C
backend: jobs1, child50s, outer60s/TERM5, non-Heavy. Actual generated C contains
the non-test InstalledArenaHost specialization and its prepare/acquire/current/
close signatures. The ordinary compiler reported two warnings: unused control
envelope and deprecated immutable Bytes.copy. Strict-warning success is not
claimed. The selected execution contains a test driver, so its C/binary is
signature/conformance evidence and cannot become an installed component.

The private C preparation entry builds LedgerLimits from primitive arguments in
MoonBit and delegates to the same typed original constructor. This avoids C
manufacturing MoonBit object layouts. That additional entry remains uncompiled;
the original Native5 result does not prove a later Source HEAD or C shim.
Result ownership/projection, non-test emission and actual embedding remain to
close. No raw Ledger or nominal pointer is serialized on wire. API/info, VM,
Wasmtime, worker, runtime wheel and public product acceptance are not added by
this entry. Production linkage must use one original C capacity/TLS provider;
the Wasmtime artifact must not silently compile a second physical provider.
