# Original worker journal material

`project_prepared_domain_original` joins the existing original Resource ticket
with the same provider's prepared physical window. It requires the current
original Host, child, region, loan, mapped view and transferred domain. Resource
DATA is sampled before and after the physical projection; a changed snapshot
is refused. The installed caller uses its registered original domain and keeps
all those live handles before any journal I/O. The projection reserves nothing
and issues no Ledger, borrow, launch, stop, settlement or cleanup authority.

The Common Host's `ClientLocalWorkerRunJournalKey` selects an already retained
Run request in its original adopted Store. Its key consists of that adoption
CID and the existing request lookup scope. A fresh validated retained row and
the same current Store are required when reading coordinates. A control
revision is not a new operation. Pre-Run provisioning is not issued through
this Run-specific path. Current Account authorization remains independent.

The private bounded Resource transport uses the existing Local original-record
codec and the existing decimal Int64 reader. Its 36 closed string fields retain
all ten groups of `BackedExecutionOriginalData`, including conservative Unknown
debt, read-use phase, pending cleanup and unavailable final usage. Missing final
usage is distinct from an observed zero census. The Resource Owner admits the
decoded cross-field relationships and returns only
`UnresolvedBackedExecutionOriginal`. Parsing those bytes cannot reconstruct the
original provider, child, ticket or physical retirement acknowledgment.

These connections do not implement the journal write/CAS or its confirmed
COMMIT observation. The same installed Host/Store transaction, current Account
checks, actual provider/child/backing binding and retained live custody remain
mandatory at that caller. Lost COMMIT response uses the original key lookup,
never a new key, reserve or replay. Cold physical adoption and retirement need
their existing Owner seam; DATA consistency cannot supply it. An old payload,
PID, FD number or equal counters cannot issue a new original.

Control/transport retention must be charged to the existing selected budgets.
The arena projection does not pay loader, process, VM, independent Store or
other unrelated allocations. No normal numerical profile is selected here.
