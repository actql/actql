# Original physical live channel

`NativeBackedLiveChannel` composes the existing original domain, one live
access/read-use, and a same-provider physical channel observation. It is not
another resource, process, Run or cleanup Owner. Its acquisition is private
trusted installed code, after complete original process/FD/control funding;
ordinary startup still has no numerical supplier.

The original domain retains the carrier before capture. Capture borrows the
caller's actual already-spawned child identity and original read/write pipe
descriptors. It opens, duplicates, transfers and closes no descriptor. The
physical record retains original PID, pipe identities, nonce and domain/backing
identity. Equal PID/FD/scalar DATA without the original Host/domain cannot
construct the nominal access. Replaced descriptors, a foreign process or changed
backing provenance fail the physical current check.

The same private channel must validate the child's actual Core Memory
observation and original provisioning frame before calling the one-shot VM
binding. The Native entry requires the selected16MiB Memory span and original
nonce; C verifies correlation, bounds and the actual original domain borrower.
These C checks alone do not prove Guest identity or authenticate a copied frame.
No pointer-shaped wire or permission Boolean substitutes for that caller.

Only the bound/current original can reach existing live-child admission.
Admission and state/report calls recheck the physical channel after the Common
Owner operation. A failed/lost reply preserves the same access and operation;
it does not permit readmission, quota reset or replay. Logical stop is the
existing Common stop; it sends no process signal. Cleanup reports use original
channel lifetime, separately from admitting new VM work.

Pending capture keeps domain close fenced even when no live access was issued.
Retirement after the trusted caller's distinct physical acknowledgements breaks
only these metadata references and the existing live-access backrefs. It does
not stop a process, close a pipe/Store/domain, return a read-use, settle a ticket,
or release backing. A sticky attempted marker prevents the same domain from
becoming a new channel generation after metadata retirement. Partial cleanup
keeps its same carrier and skips acknowledged reference retirement.

The new managed reference/marker and C external record have a new source/layout
identity. Their resident storage belongs to the existing trusted control
envelope; no current numerical profile is asserted for them. The original C
capacity provider/TLS/arena layout and product fuel/VM/transfer limits are
unchanged. Native negative-channel conformance uses invalid descriptors and
the original64-page fixture, not a VM or worker launch. Actual VM, installed
runtime/wheel and public Local acceptance remain separate.
