# Explicit Calendar installation and normal-package public six

This child of #2165 connects the already checked Calendar artifact to the
ordinary Local, Node and HTTPS Host installation. `calendarArtifact` supplies
the exact canonical table body bytes, original selection, artifact admission
limits and selection work limit. The Host snapshots those inputs, binds their
value-preserving identity, and calls the existing Common artifact admission
API. An absent installation retains the previous environment and identity
path. There is no ambient TZDB, default Calendar, new evaluator, fixed-ms
substitute or runtime capability inferred from fixture results.

The existing environment selection remains the semantic owner. Caller bytes
are copied before asynchronous Host initialization. Composed and decomposed
metadata retain distinct exact identities; configuration NFC normalization does
not rewrite artifact values. The normal public type surface covers Local,
Node and HTTPS installations. No artifact is added to an existing Run.

## Reproduction and qualifications

Use the pinned Node/toolchain and tracked `prepared-checks.mjs` for `unit` or
`typing`. The bounded normal producer and consumer are in
`prepared-release-public.mjs`; the consumer accepts an explicit artifact source
only through the existing ancestry and unchanged runtime/package checks.
`public-audit.mjs` validates the original declared six and both actual transport
inventories. External applications receive only normally installed packages
and checked fixture modules; no checkout runtime, NODE_PATH or adapter overlay
is supplied.

This establishes the original synthetic UTC public six on the recorded
artifact source and corrected fixture source. It does not establish all
Calendar profiles/refusals, Native/Wasm runtime, process-restart Calendar
reread, full Frontend, latest-main checkpoint, Hosted CI or formal publishing.
The parent bucket kernel/source-presence qualifications remain on their own
recorded sources. This child does not rewrite them as installed evidence.
