`source.aql` are independently authored controls. Snapshot and Environment CIDs
are SHA-256 over the declared sorted canonical JSON bodies, assembled with
Python rather than a product canonicalizer. The capacity block is copied from
an existing synthetic control; Calendar selection is absent. Node independently
checks every preimage, exact embedded MoonBit control, input declarations,
policy, k, result field order and the arithmetic expected rows.

Two executed MoonBit cases cover both max and weighted_sum, each through flat
and WITH text plus the independent ordinary JSON checker. They compare complete
operation JSON values and exact declared Local input bodies. JSON object key
ordering is not a semantic difference. Expected rows in `expected.json` are
designed arithmetic examples, not runtime observations.

Existing raw-score MissingScoreContract, repeated RRF occurrences, dropped
